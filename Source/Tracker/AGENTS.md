# Source/Tracker/

Per-pawn belief state. External callers (patches, interactions, UI) go through `IdeoTrackerData` exclusively; the three sub-trackers are implementation detail.

**If you're in `IdeoTrackerData` and following a call into:**
- `data.Stances.*` → `IssueStanceTracker`
- `data.Certainty.*` → `CertaintyTracker`
- `data.Opinions.*` → `OpinionCache`
- `data.CheckConversion` / `data.TryBackgroundConversion` → one-line forwarders to `Precepts/ConversionEvaluator`

**Files:**
- `IdeoTrackerData.cs` — orchestrator and public API surface; owns the three sub-trackers, wires band recache (structural band cached until `InvalidateStances`/`InvalidateStructural`; `RefreshSlowInputs` every fourth long tick); `RecacheSetpointIfStale`/`RecacheBaseOpinionsIfStale` let the UI refresh only the shown pawn, by the recache tick stamps in `CertaintyTracker`/`OpinionCache` (`InvalidateStructural` clears the setpoint stamp), and hosts `PullStance` (the debate write-path calling `ConvictionMath`); conversion methods are forwarders to `ConversionEvaluator`
- `IssueStanceTracker.cs` — per-issue `(rank, strength)` store; `GetRank`/`GetStrength`/`ShiftStance`/`SetStance`/`ApplyDecayIfNewDay` (issues with a trait target take a `ConvictionMath.ValleyStep` toward it, scaled by `CertaintyLoss.InnatePull`, others drain toward 0; before the decay it records the day start in `StanceHistory`, read through `StanceBefore`); spawn seeding (one full pass per session, `_seeded`) ends with `ApplyTraitTargets` on the newly seeded issues, and brainwipe returns targeted issues to their target; `RemapToLiveLadders` on load (see `Precepts/LadderMigration`); `ResetRanksToHeld` for the dev reset; `HoldsStance`/`HeldIssues` (issues off Don't-care, cached until a rank changes; every rank write must go through `SetRank`, which drops the cache); read by `StructuralOpinionCalculator` and `InteractionWorker_IdeologicalDebatePrecept`
- `TraitStanceTargets.cs` — static; `For(pawn, ranks)` turns the pawn's trait votes into one `TraitStanceTarget` per issue (rules: docs/design.md "Trait stance targets"). A target is a support rung or an opposed region; callers ask it `PullFrom(rank)` for the rank and strength to pull toward, and `OpposedWeight(rank)` for seeding's conviction penalty; the meme → rung map is cached (`ClearMemeCache` test hook). The optional `votes` sink receives each `TraitVote` (trait, meme or null for a direct link, weight, rungs); seeding fills it and logs it when `DebugInteractionWorkers` is on, and the opinion card fills it for the hovered row and asks `StrongestVote(rank, votes)` for the one vote to name. Read by `IssueStanceTracker` seeding, brainwipe and decay
- `StanceHistory.cs` — ranks and strengths at the start of this game day and the previous one; `Before(issue)` returns the older snapshot when present, so the opinion card's change arrows cover at least one full day; `FillMissing` records the current stance for issues with no history (called at load from `IdeoTrackerData` PostLoadInit and at a new pawn's first seeding), and `RemapRanks` follows `RemapToLiveLadders`
- `CertaintyTracker.cs` — extended certainty float, three-band setpoint, calibration scheduling, drift finalisation; advanced via the `IdeoTracker_TickInterval` patch
- `OpinionCache.cs` — base/personal opinion dicts and dirty flag; invalidated on any stance or ideo change, except that mood pulls (`fromMood` on `SetIssueStance`/`ShiftIssueStance`) set `MarkMoodDirty`, which recomputes only once the oldest pull is `IdeoTrackerData.MoodRecacheTicks` (quarter day) old; `MarkRecached` clears both; relationship cache rebuilt by `RecalculateRelationshipIdeoOpinions` (drops dead and non-local pawns); read by `ITab_Opinion`
- `CertaintyLoss.cs` — static; every read of `CertaintyLossFactor` goes through it (docs/design.md "Certainty loss factor"). `Factor` clamps the stat at 0, `Resistance` is the capped inverse for the entrench gain, `InnateFactor` recomputes the trait and gene part as vanilla's StatWorker does, `InnatePull` (factor / innate²) scales the decay step toward trait targets, `UnmovedChance` lets an unmovable debate loser turn the loss into a draw
- `ConvictionScale.cs` — conviction strength bounds and `TraitVoteStrength` (the 2/3-power curve every trait-target strength uses: seeding, brainwipe, decay), shared across subsystems; `StrengthFactor` is the diminishing-returns factor for reinforcing pulls (contemplation)
